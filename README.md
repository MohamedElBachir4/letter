# 🎓 لعبة تعليم الحروف العربية

تطبيق تعليمي تفاعلي للأطفال لتعلم الحروف العربية بطريقة ممتعة وجذابة.

## 📁 بنية المشروع

```
prof/
├── index.html              # الصفحة الرئيسية
├── game.html               # صفحة اللعبة
├── project.pdf             # ملف المشروع التوضيحي
├── images/                 # مجلد الصور
│   ├── im1.png - im12.png # صور قصة حرف الباء
│   ├── 111.png - 555.png  # صور قصة حرف التاء
│   ├── j1.png - j4.png    # صور قصة حرف الجيم
│   ├── n1.png - n4.png    # صور قصة حرف الميم
│   └── del.png            # صورة ظل الطائرة
├── audio/                  # مجلد الملفات الصوتية
│   ├── vo1.mp3 - vo12.mp3 # أصوات قصة حرف الباء
│   ├── 111.mp3 - 555.mp3  # أصوات قصة حرف التاء
│   ├── j1.mp3 - j4.mp3    # أصوات قصة حرف الجيم
│   ├── n1.mp3, n2.mp3, n3n.mp3, n4n.mp3  # أصوات قصة حرف الميم
│   ├── q1.mp3 - q8.mp3    # أصوات الأسئلة
│   ├── samaka.mp3         # صوت لعبة السمكة
│   ├── difda.mp3          # صوت لعبة الضفدع
│   ├── haiw.mp3           # صوت ربط الحيوانات
│   ├── del.mp3            # صوت لعبة الظلال
│   ├── kalm.mp3           # صوت إمساك القلم
│   ├── fara.mp3, jam.mp3  # أصوات الحوارات
│   └── *.mp3              # ملفات صوتية أخرى
└── js/                     # ملفات JavaScript
    ├── main.js            # التحكم الرئيسي في اللعبة
    ├── challenges.js      # منطق التحديات والألعاب
    ├── data.js            # بيانات التحديات
    └── audio.js           # نظام الصوتيات
```

## 🎮 المحتوى التعليمي

### التدريبات البصرية
1. 🐟 لعبة السمكة - تحريك السمكة للحوض
2. 🦁 ربط الحيوانات - ربط الحيوانات المتشابهة
3. ✈️ الظلال - اختيار الظل الصحيح
4. ✏️ إمساك القلم - الطريقة الصحيحة

### حرف التاء (ت)

### حرف الجيم (ج)

## 🚀 التشغيل

1. افتح ملف `index.html` في المتصفح
2. اضغط على "ابدأ اللعبة"
3. استمتع بالتعلم! 🎉
