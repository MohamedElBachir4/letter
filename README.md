# 🎓 لعبة تعليم الحروف العربية

تطبيق تعليمي تفاعلي للأطفال لتعلم الحروف العربية بطريقة ممتعة وجذابة.

## 📁 بنية المشروع

```
prof/
├── index.html              # الصفحة الرئيسية
├── game.html               # صفحة اللعبة
├── del.png                 # صورة ظل الطائرة
├── project.pdf             # ملف المشروع التوضيحي
├── js/                     # ملفات JavaScript
│   ├── main.js            # التحكم الرئيسي في اللعبة
│   ├── challenges.js      # منطق التحديات والألعاب
│   ├── data.js            # بيانات التحديات
│   └── audio.js           # نظام الصوتيات
└── *.mp3                  # الملفات الصوتية العربية

الملفات الصوتية:
- mokh.mp3, mom.mp3        # تحدي الكلمة المختلفة
- mak.mp3, ahsnt.mp3       # تحدي استبدال المقطع
- mawdii.mp3               # تحدي الموضع
- hadf.mp3                 # تحدي حذف المقطع
- kaw.mp3, haka.mp3        # تحدي تكوين الكلمات
- faragh.mp3, wasl.mp3     # تحدي املأ الفراغ
- loup1.mp3, loup2.mp3     # حوار الثعلب
- dob1.mp3, dob2.mp3       # حوار الدب
- far1.mp3, far2.mp3       # حوار الفراشة
- jam1.mp3, jam2.mp3       # حوار الجمل
```

## 🎮 المحتوى التعليمي

### التدريبات البصرية
1. 🐟 لعبة السمكة - تحريك السمكة للحوض
2. 🦁 ربط الحيوانات - ربط الحيوانات المتشابهة
3. ✈️ الظلال - اختيار الظل الصحيح
4. ✏️ إمساك القلم - الطريقة الصحيحة

### حرف الباء (ب)
- حوار بين الثعلب والدب 🦊🐻
- 6 تحديات تفاعلية

### حرف الجيم (ج)
- حوار بين الفراشة والجمل 🦋🐫
- 6 تحديات تفاعلية

## 🚀 التشغيل

1. افتح ملف `index.html` في المتصفح
2. اضغط على "ابدأ اللعبة"
3. استمتع بالتعلم! 🎉
