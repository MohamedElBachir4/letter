# 🎓 لعبة تعليم الحروف العربية التفاعلية

## 📖 نظرة عامة

موقع ويب تعليمي تفاعلي للأطفال مصمم لتعليم الحروف العربية بطريقة ممتعة ومشوقة، مستوحى من أسلوب **Duolingo** في التعلم التفاعلي.

## ✨ المميزات الرئيسية

### 🎨 التصميم
- واجهة عصرية وجذابة مناسبة للأطفال
- ألوان فاتحة ومريحة للعين
- أزرار كبيرة سهلة الاستخدام
- تصميم متجاوب (Responsive) يعمل على جميع الأجهزة

### 🎮 نظام اللعبة
- **نظام النقاط**: كل إجابة صحيحة = 10 نقاط
- **رسائل تحفيزية**: تشجيع مستمر بعد كل إجابة
- **المكافآت**: مكافأة خاصة كل 5 إجابات صحيحة
- **التغذية الراجعة**: رسائل فورية للإجابات الصحيحة والخاطئة

### 🔊 النظام الصوتي العربي
- **تعليقات صوتية عربية مُسجلة** لكل تحدي
- تعليقات تشجيعية عشوائية عند الإجابة الصحيحة ("أحسنت!" / "ممتاز!")
- تعليقات لطيفة عند الإجابة الخاطئة ("حاول مرة أخرى!")
- **مؤثرات صوتية ناعمة**: نقر، نجاح، خطأ
- **لا يوجد نطق تلقائي للكلمات** - يستخدم تسجيلات عربية احترافية

### 🎯 أنواع التحديات

#### تدريبات بصرية
1. **🐟 لعبة السمكة**: مساعدة السمكة للوصول إلى الحوض
2. **🦁 ربط الحيوانات**: ربط الحيوانات المتشابهة
3. **✈️ الظلال**: اختيار الظل الصحيح
4. **✏️ إمساك القلم**: تعلم الطريقة الصحيحة لإمساك القلم

#### مهارات الوعي الصوتي
1. **اختيار متعدد**: اختيار الكلمة المختلفة
2. **سحب وإفلات**: استبدال المقاطع
3. **تحديد الموضع**: تحديد موقع الحرف في الكلمة
4. **إدخال نص**: حذف المقطع وكتابة الكلمة الجديدة
5. **بناء الكلمات**: تكوين كلمات من المقاطع
6. **املأ الفراغ**: إكمال الكلمات بالحرف الصحيح

#### الحوارات التعليمية
- **حوار حرف الباء** (الثعلب والدب) 🦊🐻
- **حوار حرف الجيم** (الفراشة والجمل) 🦋🐫
- تظليل الحروف المستهدفة بلون مميز
- نطق الحوارات بصوت واضح

## 🛠️ التقنيات المستخدمة

- **HTML5**: هيكلة الموقع
- **Tailwind CSS 2.2.19**: تنسيق وتصميم الواجهة
- **Vanilla JavaScript**: البرمجة التفاعلية
- **Web Audio API**: مؤثرات صوتية ناعمة
- **Arabic Voice System**: تعليقات صوتية عربية مُسجلة
- **LocalStorage**: حفظ تقدم اللاعب

## 🚀 كيفية الاستخدام

### التشغيل المحلي

1. **تحميل المشروع**
   ```bash
   git clone [repository-url]
   cd prof
   ```

2. **فتح الموقع**
   - افتح ملف `index.html` في المتصفح مباشرة
   - أو استخدم خادم محلي:
   ```bash
   # باستخدام Node.js
   npm start
   # أو
   npx serve
   ```

3. **الوصول للموقع**
   - افتح المتصفح وانتقل إلى: `http://localhost:3000`

### متطلبات التشغيل

- متصفح حديث يدعم:
  - Web Speech API (Chrome, Edge, Safari)
  - Web Audio API
  - LocalStorage
  - ES6 JavaScript

### المتصفحات المدعومة

- ✅ Google Chrome (موصى به)
- ✅ Microsoft Edge
- ✅ Safari
- ⚠️ Firefox (دعم محدود للنطق العربي)

## 🎮 طريقة اللعب

### الصفحة الرئيسية
1. انقر على **"عرض المشروع"** لمشاهدة عرض المشروع بصيغة PDF
2. انقر على **"🎮 ابدأ اللعبة"** لبدء التحديات

### أثناء اللعبة
- **النقاط**: تظهر في الأعلى
- **التقدم**: يظهر عدد التحديات المكتملة
- **الإجابة**: انقر على الخيار الصحيح أو أكمل المطلوب
- **التالي**: يتم الانتقال تلقائياً للتحدي التالي

### اختصارات لوحة المفاتيح
- **مسافة (Space)**: الانتقال للتحدي التالي
- **Escape**: العودة للصفحة الرئيسية
- **أرقام 1-4**: اختيار الخيارات في الأسئلة

## 🔧 الوظائف المتقدمة

### حفظ التقدم
- يتم حفظ النقاط والتقدم تلقائياً في `LocalStorage`
- يمكن للطفل العودة ومتابعة من حيث توقف

### التعليقات الصوتية العربية
- **تعليقات عربية مُسجلة** لكل تحدي وإجابة
- نظام تعليقات عشوائي للإجابات الصحيحة والخاطئة
- مؤثرات صوتية ناعمة ومناسبة للأطفال
- **ملاحظة**: تحتاج لإضافة 19 ملف MP3 في مجلد `voices/`
- اطلع على `voices/README.md` للتفاصيل الكاملة

### المؤثرات البصرية
- رسوم متحركة سلسة (CSS Animations)
- تأثيرات السحب والإفلات
- جسيمات متحركة عند النقر
- تأثيرات الظل والتدرج

## 🐛 حل المشاكل الشائعة

### التعليقات الصوتية العربية
- اللعبة جاهزة للتعليقات الصوتية العربية
- **تحتاج لإضافة 19 ملف MP3** في مجلد `voices/`
- راجع `ARABIC_VOICES_SETUP.md` للإرشادات الكاملة
- إذا لم تضف الملفات، ستعمل اللعبة بالمؤثرات الصوتية فقط

### التصميم لا يظهر بشكل صحيح
1. تحقق من اتصالك بالإنترنت (لتحميل Tailwind CSS)
2. امسح ذاكرة التخزين المؤقت (Cache)
3. تأكد من استخدام متصفح حديث

### البيانات لا تُحفظ
1. تأكد من تفعيل LocalStorage
2. تحقق من عدم استخدام وضع التصفح الخاص
3. امسح البيانات وابدأ من جديد
