## 🗺️ خريطة التنقل

### للمستخدم العادي
```
ابدأ هنا ↓
index.html → انقر "ابدأ اللعبة" → game.html → استمتع!

مساعدة؟ → QUICKSTART.md
```

### للمعلم
```
ابدأ هنا ↓
README.md → GUIDE.md (قسم المعلمين) → استخدم في الفصل

نصائح؟ → GUIDE.md > للمعلمين
```

### للمطور
```
ابدأ هنا ↓
README.md → INSTALLATION.md → GUIDE.md (قسم المطورين) → ابدأ البرمجة

تساهم؟ → CONTRIBUTING.md
```

## 🔍 البحث السريع

### أريد أن...

#### أبدأ اللعبة الآن
→ افتح **index.html**

#### أفهم كيف تعمل اللعبة
→ اقرأ **README.md**

#### أثبت المشروع على خادم
→ راجع **INSTALLATION.md**

→ راجع **GUIDE.md** > إضافة حرف جديد

#### أصلح خطأ أو أضيف ميزة
→ راجع **CONTRIBUTING.md**

#### أفهم البنية البرمجية
→ راجع **GUIDE.md** > للمطورين

#### أعرف آخر التحديثات
→ راجع **CHANGELOG.md**

#### أستخدمها في الفصل
→ راجع **GUIDE.md** > للمعلمين
