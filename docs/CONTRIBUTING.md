# 🤝 المساهمة في المشروع

شكراً لاهتمامك بالمساهمة في لعبة تعليم الحروف! نحن نرحب بجميع المساهمات.

## 📋 طرق المساهمة

### 1. الإبلاغ عن الأخطاء (Bug Reports)
إذا وجدت خطأ:
- تأكد من أن الخطأ لم يتم الإبلاغ عنه مسبقاً
- افتح Issue جديد
- اشرح الخطأ بوضوح
- أضف خطوات إعادة إنتاج الخطأ
- أرفق لقطات شاشة إن أمكن

### 2. اقتراح ميزات جديدة (Feature Requests)
لديك فكرة رائعة؟
- افتح Issue جديد
- اشرح الميزة المقترحة
- وضّح الفائدة التعليمية
- أضف أمثلة إن أمكن

### 3. تحسين التوثيق (Documentation)
- إصلاح أخطاء إملائية
- توضيح تعليمات غير واضحة
- إضافة أمثلة جديدة
- ترجمة التوثيق

### 4. المساهمة بالكود (Code Contributions)
- إضافة حروف جديدة
- تحسين التحديات الموجودة
- إضافة أنواع تحديات جديدة
- تحسينات في الأداء
- إصلاح الأخطاء

## 🔧 خطوات المساهمة بالكود

### 1. Fork المشروع
انقر على زر "Fork" في GitHub

### 2. استنساخ المستودع
```bash
git clone https://github.com/your-username/letter-learning-game.git
cd letter-learning-game
```

### 3. إنشاء فرع جديد
```bash
git checkout -b feature/amazing-feature
# أو
git checkout -b fix/bug-fix
```

تسمية الفروع:
- `feature/` للميزات الجديدة
- `fix/` لإصلاح الأخطاء
- `docs/` للتوثيق
- `style/` للتصميم

### 4. إجراء التعديلات
- اكتب كود نظيف وقابل للقراءة
- أضف تعليقات واضحة بالعربية
- اتبع نمط الكود الموجود
- اختبر التعديلات جيداً

### 5. Commit التغييرات
```bash
git add .
git commit -m "✨ إضافة: وصف واضح للتغيير"
```

أنواع الـ Commits:
- `✨ إضافة:` ميزة جديدة
- `🐛 إصلاح:` إصلاح خطأ
- `📚 توثيق:` تحديث التوثيق
- `🎨 تصميم:` تحسين التصميم
- `⚡ تحسين:` تحسين الأداء
- `🔧 ضبط:` تعديلات في الإعدادات

### 6. Push للمستودع
```bash
git push origin feature/amazing-feature
```

### 7. فتح Pull Request
- اذهب إلى مستودعك على GitHub
- انقر "New Pull Request"
- اكتب عنوان ووصف واضح
- اشرح التغييرات التي أجريتها
- ارفق لقطات شاشة إن وجدت

## 📝 معايير الكود

```javascript
    return points * 10;
}

// ❌ سيء
```

### التعليقات
```javascript
// ✅ جيد - تعليق واضح بالعربية
// حساب النقاط الإجمالية للطالب

// ❌ سيء - بدون تعليق
```

### HTML
```html

    <h1>العنوان</h1>

<div class="container"><h1>العنوان</h1><p>النص</p></div>
```

## 📚 إضافة نوع تحدي جديد

### 1. أضف النوع في `js/data.js`
```javascript
{
    id: 'new-challenge',
    type: 'new-type',
    title: 'التحدي الجديد',
    // ... البيانات
}
```

### 2. أضف دالة العرض في `js/challenges.js`
```javascript
renderNewType(container) {
    // كود عرض التحدي
}
```

### 3. أضف الحالة في `renderChallenge()`
```javascript
case 'new-type':
    this.renderNewType(container);
    break;
```
